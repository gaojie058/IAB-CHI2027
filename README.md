# IAB at CHI 2027

Public website for the proposed **Second Workshop on Interpreting Agent Behavior: Understanding Agents, Humans, and Interaction**.

Website: https://gaojie058.github.io/IAB-CHI2027/

## Edit the website

- `docs/index.html`: workshop content and metadata
- `docs/styles.css`: layout, typography, and responsive styles
- `docs/script.js`: mobile navigation

The site is plain HTML, CSS, and JavaScript. No build or package installation is required. To preview, run `python3 -m http.server 8000 --directory docs` and open `http://localhost:8000`.

GitHub Pages publishes the `docs/` folder from the `main` branch after each push. The proposal source and internal review materials are maintained separately.
